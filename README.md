# 多摩市 高齢者施設マップ

高齢者の人生を絵本にする活動のための、**多摩市内の高齢者施設 95 件**を地図化したツールです。
訪問・インタビューの相談先を地図で探し、**インタビューの進捗を記録**できます。スマホ対応。

- 地図：Leaflet + 国土地理院タイル（淡色）。「すっきり／目安」は地理院最適化ベクトルタイルをMapLibre GLで描画（いずれも無料・商用可）
- データ：元Excel `tama_senior_facilities_20261029.xlsx` から自動生成（単一HTML + `data.js`）
- 記録：インタビュー状況・メモは**閲覧端末のブラウザ内に保存**（サーバー送信なし）→ CSVでExcelへ書き戻し

## 使い方（閲覧者）

- ピンをタップ → 施設の詳細（住所・電話・実人数・定員・交通・注意事項・出典）
- 詳細内の「インタビュー記録」で 未着手 / 連絡済 / 日程調整中 / 実施済 / 見送り と、連絡日・訪問日・担当・読み合わせ会・メモを記録
- ⚙ … 種別・エリア・状況で絞り込み、**地図の見え方（すっきり / 目安 / 基本）切替**、ピンの色分け（種別 / 進捗）切替
  - **すっきり** … 地理院の最適化ベクトル地図（注記を省き建物を強調）／**目安** … すっきり＋主要駅の目印／**基本** … 地理院の淡色地図（既定）
- 🔍 … 施設名・住所で検索　／　☰ 一覧 … リスト表示（進捗順）
- ⓘ … 目的・件数・駅近候補・読み方の注意事項・記録のエクスポート

### 記録の保存とバックアップ（重要）
記録は**その端末のブラウザだけ**に残ります。機種変更・共有・消去に備え、
ⓘ →「記録のエクスポート」から **CSV（Excel貼り付け用）** または **JSON（バックアップ）** を保存してください。
元Excelの S〜Y 列（インタビュー状況・連絡日・実施日・先方担当・読み合わせ会・メモ・更新日時）へ
No. を目印に転記すれば、Excel 側で全記録を一元管理できます。

## データの更新（施設の追加・修正）

元Excel が唯一の原本です。施設を直したら `data.js` を再生成します。

```bash
cd tools
python -I regenerate.py            # data/ または デスクトップの .xlsx を自動検出
python -I regenerate.py <Excelのパス>   # パス指定も可
```

- 住所→緯度経度は国土地理院ジオコーダで取得し `tools/geocache.json` に保存。2回目以降は新規住所だけ取得します。
- 生成後、`git add -A && git commit && git push` で GitHub Pages に反映。
- 同一丁目に複数施設がある場合はピンが重なるため、わずかにずらして（ジッター）全件タップできるようにしています。

## ファイル構成

```
index.html              地図本体（単一HTML・Leafletはcdnjs）
data.js                 施設・相談窓口・概要データ（自動生成、手で編集しない）
data/                   元Excelのスナップショット
tools/regenerate.py     Excel → data.js 再生成スクリプト
tools/geocache.json     住所→座標キャッシュ
```

## 出典・注意

- データ出典：多摩市けあプロ・navi、東京都有料老人ホーム一覧、サービス付き高齢者向け住宅登録、多摩市公式、各施設公式ほか（調査日 2026-10-29）
- 掲載は施設・サービス単位。同一建物・同一利用者の重複を含むため**人数の合算はできません**。
- 「未確認」は公開資料で確認できなかった値で、0人・非公表・施設不存在を意味しません。電話照会は未実施。
- エリア区分は住所からの方面目安で、最寄り駅・徒歩圏の判定ではありません。
- 多摩市立諏訪老人福祉館は 2026-10-31 閉館予定（継続活動の候補から除外）。
