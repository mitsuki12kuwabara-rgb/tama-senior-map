# チーム共有（Googleスプレッドシート＋合言葉）セットアップ手順

地図のインタビュー記録を**チームで共有**し、だれが操作しても全員に反映され、**操作者名**も残る設定です。
公開サイト（GitHub Pages）は誰でも開けますが、**記録の読み書きは「合言葉」を知っている人だけ**ができます（URLが知られても合言葉がなければ不可）。保育園アプローチマップと同じ方式です。

この一連の操作（スプレッドシート作成・合言葉決め・デプロイ）は、**あなたのGoogleアカウントで1回だけ**必要です（代理デプロイは不可）。所要5分ほど・費用ゼロ。

## しくみ

- 記録は **施設ごとに1行**（シート「記録」）。同じ施設を同時に更新したら、**更新時刻が新しいほうが残ります**。
- 更新のたびに **シート「履歴」** に、記録者名つきで1件1行ずつ積み上がります（消えません）＝「だれがいつ操作したか」。
- 地図を使う人は最初の一度だけ **名前** と **合言葉** を入れます（この端末に記憶）。
- 電波が悪いときは端末にいったん保存し、つながったらまとめて送ります（画面上部の表示が「⚠ つながりません・未送信n」→「共有中」に変わります）。
- 誤って消したり上書きしたときは、スプレッドシートの「ファイル → 変更履歴」で戻せます。
- 右端の隠し列 `ts` / `data` は地図用です。手で触らないでください。

## 手順

1. **スプレッドシートを作成**
   ブラウザで `https://sheets.new` を開く。名前は「多摩市高齢者施設マップ_記録」など任意。

2. **Apps Scriptにコードを貼り付け**
   メニュー **拡張機能 → Apps Script**。最初からある中身を全部消し、[`tools/google-sheets-backend.gs`](google-sheets-backend.gs) の中身を**全部コピーして貼り付け**、保存（💾）。

3. **シート作成と合言葉**
   スプレッドシートに戻って**再読み込み**すると、メニューに **「高齢者施設マップ」** が出ます。
   - **「① 最初の準備（シートを作る）」** → 初回はGoogleの確認画面が出るので、自分のアカウントで「許可」（「安全ではない」と出たら『詳細』→『（プロジェクト名）に移動』で続行）。
   - **「② 合言葉を決める・変える」** → チームの合言葉（8文字以上）を入力。これを地図を使う人に伝えます。

4. **ウェブアプリとしてデプロイ**
   右上 **デプロイ → 新しいデプロイ** → 歯車（⚙）→ **ウェブアプリ**。
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**　← 合言葉で守るので「全員」でOK
   - **デプロイ** を押す。

5. **URLをコピーして共有**
   完了画面の **ウェブアプリURL（`https://script.google.com/macros/s/……/exec` で終わる）** をコピー。
   このURLを担当（Claude）に伝える → `config.js` に設定して公開 → チーム共有が有効になります。
   チームの人には **地図のURL** と **合言葉** を伝えます。

## 運用のメモ

- **合言葉が漏れたら**：メニュー「② 合言葉を決める・変える」で変更。全員の地図に「合言葉がちがいます」と出るので、新しい合言葉を入れ直してもらいます。
- **コードを直した時**：「デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン『新バージョン』→ デプロイ」。URLは変わりません。
- **共有をやめるとき**：`config.js` を空に戻せば、これまでどおり端末だけで記録します（スプレッドシートの記録は残ります）。地図側でも「この端末だけで使う」を選べます。
- **無料の範囲**：Apps Scriptの無料枠に対し、数人のチームの利用はごく小さく収まります。
- 施設そのもの（95件の基本情報）は従来どおり元Excel→`regenerate.py`で管理。共有シートは「記録」だけを持ちます。
