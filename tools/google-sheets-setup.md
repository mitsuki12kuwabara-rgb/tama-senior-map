# チーム共有（Googleスプレッドシート）セットアップ手順

地図のインタビュー記録を**チームで共有**し、だれが操作しても全員に反映され、**操作者名**も残る設定です。
公開サイト（GitHub Pages）は静的なので、保存先として **Googleスプレッドシート＋Apps Script（ウェブアプリ）** をバックエンドにします。

この一連の操作（スプレッドシート作成とデプロイ）は、**あなたのGoogleアカウントで1回だけ**必要です（代理デプロイは不可）。所要5分ほど。

## 手順

1. **スプレッドシートを作成**
   ブラウザで `https://sheets.new` を開く（新規シートができます）。名前は「多摩市高齢者施設マップ_記録」など任意。

2. **Apps Scriptを開いてコードを貼り付け**
   メニュー **拡張機能 → Apps Script** を開く。
   既存のコードを全部消し、[`tools/google-sheets-backend.gs`](google-sheets-backend.gs) の中身を**全部コピーして貼り付け**、保存（💾）。

3. **ウェブアプリとしてデプロイ**
   右上 **デプロイ → 新しいデプロイ**。
   - 種類（⚙歯車）→ **ウェブアプリ**
   - 説明：任意
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**　← 重要（匿名も含む／ログイン不要で読み書きできるように）
   - **デプロイ** を押す。初回は「アクセスを承認」→自分のアカウントで許可（「安全ではない」と出たら『詳細』→『（プロジェクト名）に移動』で続行）。

4. **URLをコピーして共有**
   デプロイ完了画面の **ウェブアプリ URL（`https://script.google.com/macros/s/……/exec` で終わる）** をコピー。
   このURLを担当（Claude）に伝える → `config.js` に設定して公開 → チーム共有が有効になります。

## 仕組み・運用

- シートは自動で2枚作られます。
  - **records**：施設ごとの最新状態（段階・メモ・操作者・更新日時 など）
  - **log**：変更のたびに1行追記される履歴（日時・操作者・施設・段階・メモ）＝「だれがいつ操作したか」の記録
- 地図を開いた人は最初に**名前（ニックネーム可）**を入力します（端末に記憶）。以降の変更にその名前が残ります。名前はヘッダーの「名前を変更」から変更可。
- 地図は約30秒ごと＋画面を開いた時に最新を取得するので、**他の人の変更も自動で反映**されます。
- スプレッドシートを直接編集してもOK（records シートの該当行を直せば地図に反映）。
- 施設そのもの（95件の基本情報）は従来どおり元Excel→`regenerate.py`で管理。共有シートは「記録」だけを持ちます。

## 更新（コードを直した時）
Apps Scriptを変更したら、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** で反映（URLは変わりません）。
